# 小舟 · 本机学习助手

本机独立进程 + Playwright 专用 Chromium 浏览器 + 本地网页控制台。正常运行不占用系统鼠标，不需要 Codex 持续控制。电脑必须开机、联网；关闭控制台网页或终端不会停止后台进程。**当前为初版，真实课程尚未完成整门课程的连续运行验证。**

## 安装（macOS）

需要 Node.js 22+。首次下载后，在项目目录执行：

    npm ci
    npx playwright install chromium
    npm run build-ocr
    chmod +x 启动小舟.command 停止小舟.command

本地 OCR 的编译需要 Apple Command Line Tools。未编译 OCR 时仍可运行其他功能。

## 使用

1. 双击 `启动小舟.command`，打开 <http://127.0.0.1:4318>。
2. 填写课程或当前章节地址，保存配置；一次运行一门课程。
3. 点击“扫码登录”，在预览中扫码。独立浏览器需要重新登录，不会复制 Codex 浏览器的账号凭证。密码、验证码使用“显示登录窗口”本人处理。
4. 在“题库”页导入 JSON、CSV 或纯文本题库。`examples/answers.json` 是格式示例，只含一题实测答案，不是完整题库。
5. 可选配置 OpenAI 兼容 API 的地址、模型名和密钥；可选启用 Tavily 检索。没有密钥时仍可播放视频、匹配本地题库。
6. 选择建议、自动填写或自动提交章节作业，点击“开始运行”。默认建议模式会等待你核对；自动模式也会在缺答案、冲突或低置信度时暂停。
7. “暂停”保留浏览器。双击 `停止小舟.command` 停止后台程序和专用浏览器。

置信度门槛可在 AI 设置页调整（0～1）；仅在答案置信度高于门槛时自动处理。该数字是模型自评，不是正确率保证。

不要同时打开其他课程播放；账号只允许单路播放时，其他设备或网页会干扰。程序不能禁止其他设备登录。

## 已实现与适用范围

- 使用播放器原生播放与倍速控件，最高 2 倍。平台禁止倍速时保持允许速度；等平台显示任务完成后再切换，不伪造播放进度。
- 自动切换“下一节 / 下一任务”、章节测验、已识别的未完成目录。
- 选择题与判断题：导入答案按选项内容匹配，可处理换序；同题冲突暂停。只含字母而没有原始选项的答案不会直接套用。
- Mac Vision OCR 本地识别混淆字体；识别失败可选用视觉模型。题库优先，未命中才调用模型，相同题目在本次进程内缓存。
- 平台页面变动、强制前台、反复暂停、验证码、考试、非选择题、未确认提交结果等情况暂停提示。**不能保证所有课程可在隐藏浏览器内持续播放**，可改用显示窗口模式；不会绕过平台验证。
- AI 的置信度不代表实际正确率，建议先使用核对模式。API 功能通过模拟响应测试，需用自己的接口实测模型兼容性与额度。

## 数据与费用

控制台仅监听 127.0.0.1，接口有本机会话令牌及跨站检查。配置、题库和专用登录会话存于 `~/Library/Application Support/LocalStudyAssistant/`，目录权限 700，配置文件权限 600。密钥默认仅存在本次进程内；勾选“保存密钥”后以本机文件保存，未使用系统钥匙串加密。

视频、切换和题库匹配不使用 AI token。启用 AI 时发送题干、选项；视觉模式另发送题目截图；检索时发送题干到 Tavily。API 和检索费用由相应服务商计算。

## 开发与验证

需要 Node.js 22+。

    npm ci
    npx playwright install chromium
    npm run build-ocr
    npm test
    npm start

测试使用本地 3 秒视频和模拟章节作业，覆盖 2 倍速 → 视频完成 → 下一节 → 题库填写 → 提交 → 成绩确认 → 课程结束，以及无答案暂停、换序匹配、冲突、CSV、URL 和 AI 输出校验。测试不接触真实账号、不生成学习通学习记录。

源码：`src/worker.mjs` 运行流程，`src/probe.mjs` 页面读取，`src/core.mjs` 题库匹配，`src/ai.mjs` API，`src/server.mjs` 本机服务，`public/` 控制台。
